Can BERT keep up with the news?

I fine-tuned BERT on headlines from 2014–2016. Across two later test periods, accuracy slipped by about 2 points, while recall for hyperpartisan headlines fell by about 15.

How I tested it

  1. Combined the two manually labeled source files and created a new chronological split. After removing two missing titles and two rows with conflicting labels for the same headline, 2,196 records remained.
  2. Fine-tuned bert-base-uncased on 584 headlines and selected the checkpoint by macro F1 on a stratified validation set of 147 headlines. Both splits came from 2014–2016.
  3. Evaluated the selected checkpoint on both later periods. An exact-title check found no overlap between the early splits and either test set, and one shared title between the two test sets.

What I’d test next

The positive-label share fell from 46.5% to 40.9% across test sets. This run measures a performance change across periods, and the difference may reflect changes in topics, publishers, or label mix. It uses a single training run.

I’d compare BERT with TF-IDF plus logistic regression on the same splits, then check whether the recall gap persists across publishers and training seeds.
